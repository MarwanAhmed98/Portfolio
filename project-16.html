// Student Management System

A responsive and interactive student management web app developed using HTML5, CSS3, Bootstrap 5, and Vanilla JavaScript. The system allows users to manage student records efficiently through a clean and user-friendly interface.

Live Link → $ code-link
preview — project-16.png
// overview

💡 Key Features

  • Add / Edit / Delete Students: Full CRUD functionality with immediate UI updates.
  • Local Storage Integration: Data is saved persistently in the browser without a backend.
  • Live Search: Instantly filter students by name or email.
  • Photo Upload: Supports uploading and displaying student profile pictures.
  • Form Validation: Validates user input (name, age, email, password) with instant feedback.
  • Responsive Design: Fully functional across desktops, tablets, and smartphones.
